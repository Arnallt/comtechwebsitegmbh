The client's systems call ComTech GmbH's APIs; the APIs drive the tokenisation
engine and the smart contract layer; settlement and custody run through the
institution's own partners.

## Components

- **APIs** — REST and webhook interfaces for configuration, issuance instructions, transfers and reporting. [Read the API overview](/comtechwebsitegmbh/technology/apis)
- **Smart contracts** — audited contract libraries for permissioned and restricted-transfer tokens. [Read the smart contract overview](/comtechwebsitegmbh/technology/smart-contracts)
- **White-label** — front ends an institution runs under its own brand. [Read the white-label overview](/comtechwebsitegmbh/technology/white-label)

Each component routes to the developer documentation for full reference.
